## 🚀 Projects

### [Selate](https://github.com/Buskud0/selate)

**Windows desktop translation application · Python**

A desktop application that lets you select text and instantly translate it from English to Lithuanian.

* Local machine-translation model
* Windows system-tray integration
* Custom translation popup
* Translation history
* Configurable settings
* Background processing
* Automated executable builds
* Regression tests

**Why I built it:** A company needed a simple translation tool for their Intake Department, where employees were struggling to understand foreign-language emails. I built a lightweight desktop application specifically to solve that problem.
